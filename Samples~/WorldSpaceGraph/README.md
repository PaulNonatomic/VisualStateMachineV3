# World-Space Graph Sample

Demonstrates rendering a live VSM3 state machine graph in **world space**, floating above the agent it controls. Viewer watches AI logic and AI behaviour at the same time.

## Features Demonstrated

- `RuntimeGraphView` runtime renderer (UI Toolkit, lives in the `Nonatomic.VSM.Visualization` assembly)
- `WorldSpace` `PanelSettings` rendering a VSM3 graph in 3D
- Live state highlight + outgoing-edge emphasis driven by `StateMachineInstance.OnStateChanged`
- `RuntimeGraphTheme` customisation — the in-world graph is restyled by `Content/CreatureTheme.asset`
- Wire-style bezier edges that match the editor's wire renderer
- Click-to-poke interactivity (left-click the creature → triggers `OnPoked`)
- Free-fly camera (right-mouse to look, WASD/QE to move, Shift to sprint)

## One-Time Setup

1. Open the project in Unity.
2. Run **Tools > VSM Samples > Setup World Space Graph Sample**.
3. The installer creates `Content/CreatureGraph.asset`, `Content/CreaturePanelSettings.asset`, `Content/CreatureTheme.asset`, and `WorldSpaceGraph.unity`, and wires them onto the bootstrap.
4. If the floating panel does not appear at runtime, open `CreaturePanelSettings` and set **Render Mode = World Space** (the installer attempts this via `SerializedObject` but the underlying property name varies by Unity version).

## Running

1. Open `WorldSpaceGraph.unity`.
2. Press Play.
3. The creature wanders. Left-click it to poke it (it'll jiggle excitedly, then settle).
4. The floating graph above the creature highlights the active state and its outgoing edges in real time.
5. Fly around with right-mouse + WASD/QE to view the panel from any angle.

## Input Requirement

Camera and click controls use the **legacy Input Manager**. If your project's *Active Input Handling* (Project Settings > Player) is set to **Input System (New)** only, the controls are disabled (the sample logs a one-time warning instead of throwing) — set it to **Both** to enable them. Full Input System support is a planned follow-up.

## Customising the Look

`Content/CreatureTheme.asset` is a `RuntimeGraphTheme`. Select it to edit edge style/colour/width, node sizing and colours, the active-state highlight, port-dot colours, and more — changes show next time you enter Play. To start from scratch, create one via **Assets > Create > Visual State Machine > Runtime Graph Theme** and assign it to the **WorldSpaceGraph Bootstrap** component. Leaving the theme field empty falls back to built-in defaults.

## State Machine

```
Entry → Idle ──(OnBored)──→ Wander ──(OnArrived)──→ Idle
         │
         └──(OnPoked)──→ Excited ──(OnSettled)──→ Idle
```
